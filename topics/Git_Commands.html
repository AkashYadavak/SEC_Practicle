SOFTWARE AND DEVELOPMENT TOOLS

Git Commands

A quick reference to saving changes, working with branches, and sharing a project with a remote repository.

Course topics

Quick model: edit files, stage the changes you want, commit them locally, then push commits to share them.

1. Set up Git

Set your name and email once on your computer. Git records these details on your commits. 

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global --list

2. Start or get a project

# Create a Git repository in the current folder
git init

# Copy an existing remote repository to your computer
git clone https://github.com/username/repository.git

# See which files Git notices and what is changed
git status

3. Save a change

# Review changes before staging
git diff

# Stage one file, or stage all current changes
git add path/to/file
git add .

# Review what is staged, then create a commit
git diff --staged
git commit -m "Describe the change"

A commit is a saved checkpoint in your local repository. A clear message says what the change accomplishes.

4. Work with branches

# List local branches
git branch

# Create and switch to a new branch
git switch -c feature/my-change

# Switch back to the main branch
git switch main

# Combine a branch into the branch you are currently on
git merge feature/my-change

5. Share with GitHub

# Show configured remotes
git remote -v

# Add a remote if the repository does not have one yet
git remote add origin https://github.com/username/repository.git

# Publish the current branch and remember its upstream
git push -u origin main

# Get remote changes; stop if a merge is needed
git pull --ff-only origin main

Replace the example URL, branch, and file path with the ones for your project. A commit is local until you push it.

Useful inspection commands

# Show recent commits
git log --oneline

# Show the current branch and working-tree status
git status --short --branch

# Compare your current branch with main
git diff main

Before running cleanup commands

Commands such as git reset --hard and git clean -fd can permanently discard uncommitted work or untracked files. Check git status first, and use them only when you understand what will be removed.
